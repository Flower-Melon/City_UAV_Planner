# web 项目结构

`web/` 是城市仿真的操作界面。在项目根目录运行 `node web/serve.cjs` 启动。

左侧「巡查助手」同时显示当前情况、核验建议和现场通报。收到指令、实际开始搜索、发现异常或追踪状态变化时生成研判。抓拍和路口观测随通报显示，同一目标的后续变化归在原卡片；点击引用可跳转到相应证据，较早的通报可以折叠。地图下方提供机队、场景和图层，页面打开时工具面板收起。

仿真巡查通过 YOLO 人框和曝光时的场景人物位置关联证据。唯一匹配时，沿用场景登记的人物类别和 ID，连续照片归入同一张人物卡。

每轮规划与巡查的执行日志保存在 `output/mission-briefings/<会话编号>.jsonl`，其中 `mission_id` 可与各区域的 `task.json` 对照。

「历史输出」可按任务查看助手已经发布的研判和补充问题。每轮有编号的任务按生成顺序将输出写入各区域的 `output/<序号>/briefings/000001.md` 等文件。每份文件包含生成时间、助手原文和引用依据。网页用于回看的结构化记录保存在 `output/mission-briefings/<会话编号>/`，其中也保留尚未分配区域编号的会话输出。

打开「机队」即可同时查看所有飞行中无人机的实时画面。展开监控墙后，可以在顶部切换「全部无人机」和「飞行中」，默认显示飞行中的无人机。「场景」通过同一个入口选择和添加场景，街区目标的按钮集中在「操作」菜单。「图层」左侧控制地图显示，右侧查找并查看对象。

在「场景」的街区目标列表中，可直接对病人点击「派机送药」，对持刀人员点击「派机处置」。系统使用「机队」中的飞行参数并自动选择空闲无人机。现场动作结束后，无人机会按导航航线返航降落，结果按目标编号显示。期间仍可操作其他目标。

在「机队」顶部点击「飞行设置」，按机号编辑飞行速度上限和导航高度上限。各任务读取实际执飞无人机的速度上限。区域巡查、送药和现场处置读取导航高度上限。巡查高度、拍照间距和监控高度使用各自流程的设定。

配置保存在当前浏览器，用于新提交的任务。旧任务配置合并时，同一字段优先沿用区域巡查的值。旧配置仍保留在浏览器中。

## 子文件夹分工

| 目录 | 功能划分 |
|---|---|
| `js/` | 前端部分，实现页面交互。 |
| `css/` | 定义页面外观。 |
| `server/` | 后端部分，处理网页请求。 |
| `utils/` | 脚本工具，连接 Python 功能与仿真环境。 |
| `assets/` | 存放页面素材。 |

## 输出目录

每个区域分配一个连续编号目录，由网页调度端在启动无人机前统一创建。同一区域的低空巡查和高空监控共用这个编号；一次确认多个区域会创建多个编号目录，不再增加 `task_1/` 层级。已有历史目录保持原样。

```text
output/000001/                  一个区域的高低空联合任务
├─ task.json                    所属网页任务、区域ID、飞行/测速参数及两架无人机ID
├─ search/                      低空巡查
│  ├─ events.json               异常与漏拍记录（发生时生成）
│  ├─ capture/
│  │  ├─ 000001.jpg             全部巡查原图，按拍摄顺序编号
│  │  ├─ route.json             巡查航线及返航路径
│  │  └─ frame.json             照片文件名、拍摄位置与道路编号
│  ├─ yolo_detection/           仅检出人车时生成
│  │  ├─ 000001.json            原图像素框、置信度及裁剪路径
│  │  ├─ 000001.annotated.jpg   YOLO标注图
│  │  └─ crops/                 人车目标裁剪放大图
│  └─ llm_analysis/
│     ├─ 000001.json            单张原图的各目标判断与YOLO框
│     └─ abnormal/              异常红框图片，与巡查原图同名
└─ monitor/                     高空车辆测速
   ├─ latest.json               最新测速与fusion联合研判（持续更新至停止监测）
   ├─ capture/                  仅保存触发超速证据的原图
   │  └─ 000123.jpg
   ├─ 000123.json               对应帧的超速记录
   └─ 000123.annotated.jpg      超速标注图
```

`task.json` 保存任务关联信息，不作为完成标记；低空巡查结束后，高空监控仍可继续更新。`search/` 和 `monitor/` 的产物随对应流程运行生成。ck
